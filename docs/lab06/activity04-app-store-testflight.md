# Activity 04 – App Store / TestFlight

**Status: NOT DONE. Requires an Apple Developer Program account and a real iOS build.**

## Steps (to be done by the student)
1. Join the Apple Developer Program.
2. Create an App ID with bundle identifier `com.fitflow.redesign`.
3. Build iOS: `eas build --platform ios --profile production`.
4. Upload to App Store Connect: `eas submit --platform ios`.
5. In TestFlight, add internal testers and wait for build processing.

## Record only real results
- [ ] App record created in App Store Connect
- [ ] Build uploaded
- [ ] Internal testers invited

If you have no Apple account, write this in your report: "Not performed (requires paid Apple Developer account)".
